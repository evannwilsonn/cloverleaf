# Cloverleaf collected data

Append-only landing zone written by the `collect` workflow every 30 minutes:
`captures/<UTC date>/<HHMMSS>_<run_id>.jsonl` (one line per camera) and `weather/<UTC date>/<HHMMSS>.jsonl`.
The first runs on 2026-10-09 were recorded from a development machine before the schedule went live.
